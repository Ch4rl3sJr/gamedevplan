# JAMTEC - Planejamento de Jogo Digital

Atividade interativa em HTML, CSS e JavaScript para planejamento de jogos digitais.

## Arquivos

- `index.html` — estrutura da página
- `style.css` — estilos visuais
- `script.js` — funcionalidades: progresso, salvar/carregar, exportar/importar JSON e impressão em PDF

## Como usar

Abra `index.html` no navegador.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde a publicação.
